Model methodology & setup

Projections: Built from game-by-game playoff logs. Per-round means are blended with GP-adjusted weights — base R1 0.20 / Semis 0.30 / CF 0.50, each scaled by (games played ÷ series length) then renormalized. Points rebuilt from components as 2·FGM + 3PM + FTM. Pure player-form, no opponent adjustment.

Edge: Each stat has σ (pooled std dev across all playoff games). Given a sportsbook line L, the over probability is P(over) = 1 − Φ((L − μ)/σ), where Φ is the normal CDF. Green flags P>55%, red flags P<45%.

Live odds: Switch Mode to "Live" and paste your the-odds-api.com key. The dashboard queries the NBA player props markets (player_points, player_rebounds, player_assists) and auto-fills the line boxes. Without a key, type lines manually.

Deploy: Push these files to a GitHub repo, enable Pages (Settings → Pages → main / root). The key is never committed — it lives only in the browser input.
